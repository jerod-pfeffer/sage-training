Sage / TrainingBlock planner

Settings

The plan lives in a GitHub repo. This page reads it from there; your token, kept on this phone only, lets it save your moves, check-offs, and notes back.

Add the next block

Paste the block JSON from the training chat. A block with the same id replaces the old version; a new id is added alongside. The week you're looking at picks its block by date.

How the week works
Each row is a day of the plan. Drag the handle on the right to swap two days when life moves — the whole day travels (its sessions, check-offs, and notes go with it). Tap a day for its sessions, tap a session for this week's exact prescription. Changes apply to that one week only; the plan itself never changes. Reset to plan in a day's sheet puts the week back.
How to get a token
On github.com: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Under Repository access choose Only select repositories and pick this repo. Under Permissions → Repository permissions set Contents to Read and write. Pick the longest expiration offered, generate, and paste the github_pat_… value above. Without a token the app is read-only and changes stay on this phone until you reload.
Block JSON, briefly
A block has an id, a name, a Monday start date, a list of weeks (label + focus), rules, a default week of seven day-type ids (Mon–Sun), the dayTypes those ids point to, and the sessions each day type contains. Any exercise can carry a byWeek map so the prescription changes across the block, and a weeks list to appear only in some weeks. The chat produces this for you at the end of each block — you shouldn't need to write it by hand.
